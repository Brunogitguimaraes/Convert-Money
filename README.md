# Convert-Money - Conversor de Moedas

**Convert-Money** é uma aplicação web simples e interativa para converter entre diferentes moedas, como Real Brasileiro (BRL), Dólar Americano (USD), Euro (EUR), Libra Esterlina (GBP) e Bitcoin (BTC). A interface oferece uma experiência fluida com a possibilidade de converter entre várias moedas em tempo real.

## Descrição

O **Convert-Money** foi criado para facilitar o processo de conversão de moedas de maneira rápida e intuitiva. A aplicação permite que os usuários insiram um valor em uma moeda e obtenham seu equivalente em outra moeda selecionada. O design é simples e acessível, com a inclusão de um som de caixa registradora para tornar a experiência mais divertida.

## Funcionalidades

- **Conversão de Moedas**: O usuário pode converter valores entre várias moedas, incluindo Real Brasileiro, Dólar Americano, Euro, Libra Esterlina e Bitcoin.
- **Entrada Dinâmica**: A aplicação atualiza o valor convertido imediatamente após o clique no botão "Converter".
- **Interface Intuitiva**: Facilidade para escolher as moedas de origem e destino.
- **Design Responsivo**: A interface foi projetada para se ajustar a diferentes tamanhos de tela, proporcionando uma boa experiência em dispositivos móveis e desktops.
- **Som Interativo**: Ao realizar a conversão, um som de caixa registradora é reproduzido para tornar a interação mais divertida.

## Tecnologias Utilizadas

- **HTML**: Estruturação da página e conteúdo.
- **CSS**: Estilo e design da página.
- **JavaScript**: Lógica de conversão de moedas e interação com o usuário.
- **Áudio**: Inclusão de som interativo para a conversão.
